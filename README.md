## About Me

Computer Science student at **Fatima Jinnah Women University (FJWU)**

Full-Stack Developer passionate about building **practical, scalable, and user-focused applications**.

I work primarily with **React.js, Next.js, Node.js, Express.js, and PostgreSQL**, with experience developing REST APIs, authentication systems, dashboards, inventory platforms, and real-time applications.

I'm also exploring **Artificial Intelligence, Machine Learning, and Generative AI**, especially how intelligent systems can be integrated into real-world software.

I enjoy taking an idea from **concept → architecture → implementation → working product**.

Outside development, I enjoy reading novels, designing graphics, experimenting with recipes, and constantly learning something new.
